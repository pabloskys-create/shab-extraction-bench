# shab-extraction-bench

Benchmark measuring how reliably LLMs extract structured JSON from
German-language Swiss commercial-register notices (SHAB).

- 170 hand-annotated notices (120 dev, 50 held-out test set)
- 7 models + 2 baselines, bootstrap confidence intervals
- Gold audited with model consensus and prompt-rule checks

Work in progress: results and full write-up coming soon.
